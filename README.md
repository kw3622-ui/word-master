# 단어 마스터 노트 v0.0.6

브라우저에서 실행하는 가족용 영어 단어 학습 앱. 초등 기본·심화, 중등 기본·심화, 고등 기본·심화를 모두 자유롭게 선택합니다.

## v0.0.6 변경

선택 버튼의 체크 표시를 제거하고 높이·여백을 줄였습니다. 일반 버튼은 흰색, 선택 버튼은 오늘의 학습에서 금색/다른 설정에서 진한 녹색으로 구분합니다. 단어장은 기본 3열(350px 이하 2열), 나머지는 글자 길이에 맞춰 한 줄 우선으로 배치하며 필요하면 줄바꿈합니다. 시작·확인 버튼 크기는 유지합니다.

## v0.0.5 변경

오늘의 학습·직접 학습 설정·내 설정의 모든 드롭다운(11곳)을 선택 버튼으로 바꿨습니다. 선택은 배경색과 체크로 표시하며 버튼 높이는 최소 44px입니다. 단어장과 문제 유형은 2열로 배치합니다. 주관식에서는 객관식 보기 수와 뜻 떠올리기 설정을 숨기며, 다시 객관식/혼합을 고르면 기존 설정이 나타납니다. 보기 수·기기별 선택 저장과 학습/채점 방식은 유지합니다.

## v0.0.4 변경

오늘의 학습과 직접 학습 설정에서 객관식 4·6·8개를 선택하며 기본은 6개입니다. 선택은 기기·프로필별로 공유·저장합니다. 정답·오답은 화면 중앙 모달에 표시하고, 내용은 내부 스크롤, 확인 버튼은 하단에 고정합니다. 예문은 펼쳐 볼 수 있습니다. 마지막 문제는 학습 결과 보기로 이동합니다. 네이티브 dialog로 배경 조작과 초점을 제한하며 연속 터치/Enter로 결과를 건너뛰지 않게 보호합니다. 서로 다른 보기 후보가 부족하면 가능한 개수만 표시합니다.

## v0.0.3 변경

오늘의 학습에 ‘보기 전에 뜻 떠올리기’ 켜기/끄기를 추가했습니다(기본 켜기). 선택은 기기·프로필별로 저장합니다. 켜면 객관식에서 단어와 발음 듣기를 먼저 보여주고, ‘보기 확인하기’를 누르면 선택지가 나타납니다. 시간 제한·강제 대기·입력은 없으며 혼합의 객관식 문제에도 적용됩니다. 새 단어 카드는 뜻을 먼저 보여줍니다. 결과는 기존 객관식으로 기록하며 주관식 숙련도로 인정하지 않습니다. 직접 학습 설정은 기존 방식으로 동작합니다.

## v0.0.2 변경

오늘의 학습에서 객관식(기본), 주관식 뜻 입력, 주관식 철자 입력, 혼합을 직접 선택합니다. 복습 이력이 있어도 선택한 유형으로 출제합니다. 선택은 현재 로그인 동안 유지되며 다시 로그인하면 객관식으로 시작합니다. 단어 추천·복습 일정·숙련도 기준은 그대로입니다.

## 사용법

- 홈의 **오늘의 학습**: 선택한 단어장의 복습 단어와 새 단어를 추천합니다. 새 단어는 뜻·발음·예문을 먼저 보고 퀴즈로 확인합니다.
- **직접 학습 설정**: 모든 난이도, 뜻 고르기, 뜻 직접 입력, 철자 직접 입력, 혼합을 선택할 수 있습니다.
- **학습 현황**: 처음 만나는 단어 / 익히는 중 / 잘 기억해요. 뜻·철자 숙련도는 따로 계산합니다.
- **잘 기억해요**: 뜻 또는 철자를 보기 없이 서로 다른 한국 날짜 기준 3일에 정답으로 기억한 상태. 같은 날 반복 정답은 하루로만 인정합니다. 해당 유형을 틀리면 그 유형의 연속 성공 일수가 초기화됩니다.
- **복습 간격**: 1·3·7·14·30일. 오답은 다음 날 다시 복습합니다. 기본 새 단어 5개·복습 10개이며 내 설정에서 조절합니다. 복습이 남으면 다음 학습으로 이어집니다.
- **단어 가져오기**: 부모님/관리자 → CSV 파일 또는 엑셀 표 붙여넣기 → 미리보기 → 반영. XLSX 자체는 지원하지 않으며 CSV UTF-8 저장 또는 표 복사를 사용합니다.
- **기록 보존**: 기존 기록과 streak는 남겨 두고 새 복습 정보를 추가합니다. 같은 철자·같은 뜻은 진도를 공유하며 다른 뜻은 분리합니다. 의미가 다른 기존 중복 단어의 옛 streak를 임의로 다른 의미에 배분하지 않습니다.
- **저장 실패**: 답안은 해당 기기의 localStorage에 임시 저장합니다. 같은 프로필로 로그인해 이전 결과를 저장할 수 있습니다. 브라우저 데이터 삭제·시크릿 창 종료 시 임시 기록이 사라질 수 있습니다. 완전한 오프라인 앱은 아닙니다.
- 남매 순위 대신 개인별 학습 현황을 중심으로 보여줍니다. 기존 회차 점수는 학습 기록에 유지합니다.

## DB 적용과 배포

SQL은 기존 `words`, `profiles`, `progress`, `notebook`, `rounds`, `app_settings` 스키마가 있는 프로젝트 기준입니다. 프런트 배포 전에 SQL을 적용합니다. 이번 연결된 프로젝트에는 적용 완료했습니다. 기본 데이터의 삭제·일괄 초기화는 없습니다.

`progress.learning`은 기준 단어 ID별 JSON입니다. 기존 `(user_id,word)` UNIQUE와 옛 streak를 보존하면서 동음이의어를 구별합니다. `rounds.client_round_id`로 재시도 중복을 막고, 한 RPC 트랜잭션에서 진도·오답노트·기록을 저장합니다. 사용자 행 잠금으로 새 저장 함수끼리의 동시 갱신을 직렬화합니다. 구버전 앱은 새 저장 잠금을 사용하지 않으므로 업데이트 후 열린 구버전 탭은 새로고침해야 합니다.

가져오기는 1~2,000개를 한 트랜잭션으로 처리합니다. 파일 내 중복·모호한 기존 단어는 거절하고, 기존 단어 id·철자·난이도는 고정합니다. 뜻·품사·예문을 갱신할 수 있습니다. 단어 삭제 기능은 제공하지 않습니다. 수정 시 preview 시점의 원문과 비교해 충돌을 거절합니다.

검증: 순수 규칙 26개, 실제 DB에서 anon 역할의 저장/중복/동일일/의미 분리/잘못된 비밀번호/원자성/가져오기 충돌 테스트 통과. 브라우저로 로그인·신규 카드·정답·오답·중도 저장·고등 철자 학습·CSV/표 미리보기 확인. 폭 390px/1100px에서 가로 넘침 없음. 실사용자 비밀번호와 Gemini 키 원문은 테스트용으로 조회하거나 출력하지 않았으며 유료 AI 실제 호출은 수행하지 않았습니다.

## 기존 보안 한계 (해결 완료로 간주하면 안 됨)

현재 서비스는 기존의 공유 가족용 프로필/비밀번호 구조를 유지합니다. 6개 public 테이블에 RLS가 없고 anon 권한이 넓습니다. 새 RPC는 SECURITY INVOKER와 비밀번호 검사를 사용하지만 기존 직접 테이블 접근을 막는 보안 경계가 아닙니다. 프로필 비밀번호는 기존 평문 구조이며 관리자 비밀번호와 Gemini 키도 app_settings에서 브라우저가 접근 가능한 구조입니다.

여러 불특정 사용자에게 공개하기 전 Supabase Auth, 사용자별 RLS, 관리자 정책, 서버 측 AI 호출로 전환해야 합니다. RLS만 즉시 켜면 기존 앱 접근이 막힙니다. 이번 릴리스는 이 구조를 안전하게 전환했다고 주장하지 않습니다. 확인된 Supabase 권고: https://supabase.com/docs/guides/database/database-linter?lint=0013_rls_disabled_in_public

## 어휘 보완 근거와 범위

기존 4,493개 항목과 대조해 빠진 기초 인사, 가족·생활, 학습 동사, 디지털 생활 표현을 우선한 60개를 추가했습니다. 초등기본 24 / 초등심화 18 / 중등기본 13 / 중등심화 2 / 고등기본 1 / 고등심화 2. 기존 목록 전체를 교육과정 인증 목록으로 검수했다는 의미는 아닙니다.

Cambridge 어린이 목록과 Oxford 핵심 어휘의 목적을 참고했으며, 두 기관 목록을 통째로 복제하거나 특정 학교급과 CEFR이 공식 대응한다고 표시하지 않았습니다. 학교급 분류와 예문은 이 앱을 위해 선정·작성했습니다.

- https://www.oxfordlearnersdictionaries.com/about/wordlists/oxford3000-5000
- 간격을 둔 학습과 회상 퀴즈: https://ies.ed.gov/ncee/wwc/PracticeGuide/1

## 되돌리기

프런트는 Git 이력의 이전 커밋으로 되돌릴 수 있습니다. 추가한 DB 열은 기존 앱과 호환되므로 즉시 삭제할 필요가 없습니다. 신규 학습 기록과 단어를 삭제하는 자동 롤백은 제공하지 않습니다. 새 기록을 보존한 상태에서 필요한 복구 범위를 결정합니다.
